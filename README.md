# Luddites love

*Marginalia from Strangers*: a special edition for Jorien, made from six and a half years of Google reviews of [Luddites Books & Wine](https://www.luddites.be), Hopland 34, Antwerp.

A single static page (`index.html` plus `assets/`), served with GitHub Pages from the `main` branch. No build step: edit, commit, push.

The page asks search engines not to index it. The Jip illustration belongs to the studio that signed it; the book covers, bookmarks and building drawing belong to Luddites.
